# 刻度（Praxis Path）

一个以项目为锚点、以验证为驱动的本地优先个人任务管理系统。它围绕“现实触发 → 问题 → 方案 → 结果 → 验证 → 修正”组织实践，而不是围绕日期堆积待办事项。

## 功能

- 项目创建、编辑、筛选、搜索、状态流转与删除
- 问题、方案、结果节点的管理、排序和双轨日志
- 里程碑验证方式、通过标准、结果和感受
- 里程碑或项目结束后的结构化审视
- IndexedDB 本地实时持久化
- Chrome / Edge 桌面版自动文件快照、历史恢复与平衡保留策略
- JSON 备份导出、合并导入和覆盖恢复
- 只读分享：把单个项目导出为自包含 HTML 快照，上传静态托管后供他人查看
- 响应式桌面优先界面

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器访问终端输出的本地地址。工作数据实时保存在该地址对应的 IndexedDB 中；桌面版 Chrome / Edge 可以在“数据设置”中授权一个电脑文件夹，建立浏览器之外的自动快照。

## 质量检查

```bash
npm run lint

npx playwright install chromium

```

## 只读分享（静态快照）

把指定项目导出成一个自包含的只读 HTML 文件：项目数据内嵌在文件里，查看者用浏览器打开即可看到路线图、节点内容（含 Markdown/公式/代码高亮）、可选的里程碑与复盘，但不存在任何修改入口——只读是结构性的，查看页中没有写入代码路径。

### 使用步骤

1. 一次性准备（或 viewer 代码更新后重跑）：`npm run build:share-template`，生成 `public/share/viewer-template.html`（产物已 gitignore，只存在于本机）
2. 打开项目 → 点“分享”→ 勾选内容范围（里程碑默认包含，复盘默认不包含）、选择主题、可选设置口令 → 生成文件
3. 把文件上传到任意静态托管即获得只读链接，例如：
   - Netlify Drop：浏览器拖拽即用
   - Cloudflare Pages / GitHub Pages：放入仓库或直接上传
4. 更新内容：重新生成并**同名上传**，链接保持不变；撤销分享：删除线上文件

### 数据安全边界

- 除上传的这一份快照文件外，本地数据不会离开这台电脑；本机不开端口、无常驻服务、无账号体系
- 口令模式：整个数据（含项目名）以 AES-GCM-256 加密嵌入，密钥由口令经 PBKDF2-SHA256（31 万次迭代、随机盐）派生；口令不保存在任何地方，忘记即无法恢复
- 诚实说明：口令加密防的是链接泄露与托管平台翻看文件；若托管方恶意篡改页面代码，仍可能窃取口令——对高敏感内容请选择可信托管或不要分享
- 无口令模式下，任何获得链接的人都能查看内容，请只用于不敏感的项目

## 数据安全

建议在“数据设置”中连接一个普通文件夹或 OneDrive 同步文件夹。数据修改静默 10 秒后会自动创建不可变快照，并按“24 小时内最多 10 份、30 天内每天一份、更早每月一份”自动保留。清理站点数据不会删除这些文件，但之后需要重新选择该目录。手动 JSON 导出仍作为额外的可携带备份方式。
